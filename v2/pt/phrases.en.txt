# What each Portuguese phrase in `phrases.txt` means, in English.
#
# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain is not underlined at all, so a translation in
# progress simply shows fewer phrases rather than showing empty ones.
#
# These glosses are written by hand and are not derived from any licensed
# corpus. To translate this pack for a reader of another language, copy this
# file to `phrases.<code>.txt` and translate the right-hand side; the patterns
# on the left are the join key and must not change.
#
# The register is the register of the pack's glosses: terse, verbs with "to",
# no examples. Where the phrase is vulgar the gloss says so, because a learner
# who meets `filho da puta` in a subtitle needs to know what it costs to say.
