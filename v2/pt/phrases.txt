# Portuguese multi-word expressions: the patterns. Hand-curated — not generated
# by dictgen.
#
# Format: one pattern per line, `#` comments ignored. What each one *means* is
# in `phrases.<meta>.txt`, joined on the pattern — the same split `lex.txt` and
# `gloss.<meta>.txt` make, for the same reason. Which phrases exist is a fact
# about Portuguese; what they mean is a fact about a pair of languages.
#
# A pattern is a sequence of slots matched against consecutive tokens. Each
# slot matches a token's **root** or its normalised surface, so a pattern whose
# head inflects is written in the citation form (`ter que` catches `tem que`,
# `temos que`, `tinha que`) and an invariant phrase is written just as it is
# read (`no entanto`). `*` is a gap of up to four tokens; Portuguese needs none.
#
# There is no frequency data behind these — the rank list is unigram — which is
# why a phrase carries no band and never enters the band histogram. See NOTICE
# at the repo root.
#
# ## What belongs here
#
# Only phrases where the word-by-word reading misleads. `fim de semana` is not
# here: "end of week" already teaches it, and an underline over a phrase the
# reader can decode is noise that makes the ones that matter easier to ignore.
# Transparent multi-word prepositions (`perto de`, `longe de`, `ao lado de`)
# are out for the same reason, as are `mais tarde`, `meia hora` and `ontem à
# noite`, which the corpus reports as units but which mean what they say.
#
# ## Every pattern here was measured before it shipped
#
# Spanish's list was written from knowledge of the language. This one was
# written the same way and then checked with `npm run measure:phrase-fit --
# --lang pt`, which runs the shipping matcher over a subtitle sample and reports
# which patterns fire and on which surfaces. **No count from that run is
# recorded in this file**: the phrase list carries no frequency data, which is
# what keeps it out of the band histogram and off the licence of `ranks.txt`.
# The numbers, and the three classes of mistake they caught, are in
# `tools/measure/README.md`.
#
# What the check changes here is which patterns exist. Three kinds were dropped
# or rewritten because of it:
#
#   - Right about Portuguese, wrong about the Brazilian corpus the pack teaches
#     from: `estar a`, the European progressive, is mostly `está a caminho` — a
#     preposition, not a periphrasis. `ter sono` is real and almost unwritten,
#     because Brazilians say `estar com sono`.
#   - Wrong in shape: `fique quieto` is one imperative of one verb wearing a
#     pattern's clothes.
#   - Unreachable from the citation form: `vale` is a headword with an empty
#     root column — it is both "valley" and "is worth", and the pipeline will
#     not assert a derivation it cannot choose between — so `valer a pena`
#     cannot catch the commonest spelling of the phrase, and `vale a pena` sits
#     below it as a second line. That one was found by reading a text in the
#     running app, where the underline simply was not there.
#
# Where a pattern has a live literal reading as well as its idiomatic one
# (`dar para` is "to face onto" as well as "to be possible"; `tratar de` can be
# "to be about"), the gloss carries both senses rather than the phrase being
# dropped. A gloss that shows the reader the choice is more use than silence.
