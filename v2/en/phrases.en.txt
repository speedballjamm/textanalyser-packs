# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain is not underlined at all, so a translation in
# progress simply shows fewer phrases rather than showing empty ones.
#
# Glossing English in English, this file keeps the pack's own convention: a
# gloss never explains a phrase using the phrase. `give up` is "to stop trying,
# to surrender", never "to give up".
#
# To translate this pack for a reader of another language, copy this file to
# `phrases.<code>.txt` and translate the right-hand side; the patterns on the
# left are the join key and must not change.
